## 🤖 Project AI Integration & Governance

This project utilized a **Large Language Model (LLM)** configured as a **Senior Data Architect Advisor.**

**AI Persona Configuration:**

* **Role:** Senior Data Architect / .NET Developer Advisor.

* **Primary Task:** Architectural validation, SQL DDL drafting, and Python ETL boilerplate generation.

* **Human Oversight:** All architectural decisions, data normalization logic, and final code reviews were performed by the Lead Developer.

**System Directives:**

The AI was instructed to prioritize **Enterprise-grade performance** (SQL indexing, PEP 8 compliance) and **Healthcare Data Ethics,** ensuring a "Portfolio-ready" final product.
